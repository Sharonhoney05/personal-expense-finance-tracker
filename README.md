Personal Expense & Finance Tracker

A Python-based personal finance application that helps users record income and expenses, organize transactions by category, and monitor their finances.

Features

- Add income with categories
- Record expenses with categories
- Automatic balance calculation
- View transaction history with dates and categories
- Filter transactions by category
- Generate monthly income and expense summaries
- Visualize income vs. expenses using a bar chart
- Validate transaction amounts
- Store transactions in an SQLite database

Technologies Used

- Python
- SQLite
- Matplotlib

How to Run

1. Install Python 3.

2. Install Matplotlib:
   
   "py -m pip install matplotlib"

3. Open the project folder in your terminal.

4. Run the application:
   
   "py main.py"

Project Structure

- "main.py" — Application logic and menu
- "database.py" — Database creation and transaction operations
- "finance.db" — SQLite database created by the application

Learning Outcomes

This project demonstrates Python programming, functions, input validation, SQL database operations, data filtering, financial calculations, and data visualization.
